# Learn5G

เครื่องมือสำหรับครู: สร้างเกมห้องเรียน สร้างสื่อการสอน เครื่องมือ AI และสั่งทำนวัตกรรมตามแผนการสอน
ธีมขาว-ดำ มินิมอล มีโหมดสว่าง/มืด

## ระบบ

- **สร้างเกม** `/create` ชุดคำถาม + เปิดห้องเล่นด้วยเลข 6 หลัก (`/play` นักเรียนไม่ต้องล็อกอิน) หลายรูปแบบการเล่น รายงานผล
- **สร้างสื่อการสอน** `/studio` ตัวแก้ไขแบบ Canva / Word แม่แบบหลายร้อยแบบ ส่งออก PDF/รูป
- **เกม AI** `/ai-game` และ **ใบงาน AI** `/worksheet` สร้างคำสั่งให้ Gemini
- **สั่งทำนวัตกรรม** `/innovation` (แพ็กเกจ Master) ครูส่งแผนการสอน ทีมงานส่งลิงก์ภายใน 3-7 วัน
- **แพ็กเกจ** `/pricing` Plus 99 / Pro 199 / Master 299 บาท ต่อ 30 วัน จ่ายด้วย QR พร้อมเพย์ ตรวจสลิปด้วย EasySlip
- **หลังบ้าน** `/dev` สมาชิก, แพ็กเกจและสิทธิ์ (แก้ได้ทุกค่า), งานนวัตกรรม, การชำระเงิน, สถิติเข้าเว็บ

## สิทธิ์ของแพ็กเกจ

เก็บในตาราง `plan_entitlements` (free / plus / pro / master) แก้ได้ที่หน้า Dev > แพ็กเกจและสิทธิ์:
จำนวนชุดคำถาม, จำนวนสื่อ, พื้นที่ไฟล์ (MB), Discover, เกม AI, ใบงาน AI, งานนวัตกรรมต่อเดือน, จำนวนครั้งที่แก้ได้ต่องาน, ข้อความเพิ่มบนการ์ด
ราคาอยู่ที่ `src/lib/plans.ts` (คิดฝั่งเซิร์ฟเวอร์เท่านั้น)

## Stack

Next.js 15 (App Router) + React 19 + TypeScript + Tailwind + Supabase (Auth / Postgres / RLS / Storage) + framer-motion

## เริ่มใช้งาน

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run selftest
```

ตัวแปรสภาพแวดล้อมดูที่ `.env.example`
ไฟล์ใน `supabase/migrations/` รันเองตามลำดับใน Supabase SQL Editor (ทุกไฟล์รันซ้ำได้)
