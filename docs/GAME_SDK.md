# Learn5G Game SDK: ทำให้เกมบันทึกดาว/ตรา/รายงานได้

เกมที่เปิดจากเว็บหลักผ่านหน้า `/play/[id]` จะได้รับ "โทเคนการเล่น" อายุสั้น (4 ชั่วโมง) ที่ผูกกับนักเรียนและเกมนั้น
SDK เป็นไฟล์ JS เดียว ไม่มี dependency ใส่แล้วเกมเดิมทำงานต่อได้ปกติ (ถ้าเปิดเกมตรงๆ ไม่มีโทเคน SDK จะเงียบ)

## ติดตั้ง (1 บรรทัด)

```html
<script src="https://<โดเมนเว็บหลัก>/learn5g-sdk.js"></script>
```

## ส่งผลเมื่อจบด่าน/จบรอบ

```js
Learn5G.reportResult({
  levelKey: 'level-3',          // ชื่อด่าน (ไม่บังคับ)
  correct: 8,                   // ข้อที่ถูก
  total: 10,                    // ข้อทั้งหมด
  score: 1200,                  // คะแนนในเกม (ไม่บังคับ)
  durationSec: 95,              // เวลาที่ใช้ (ไม่บังคับ)
  mistakes: ['ครึ่งชั่วโมง', 'บวกทด'] // แท็กหัวข้อที่ตอบผิด -> ขึ้น "จุดที่ควรเสริม" ในรายงาน
}).then(function (res) {
  // res = { stars, starsTotal, streak, newBadges, buddyEvolved, ... } หรือ null ถ้าไม่ได้บันทึก
});
```

- เว็บหลักจะแสดงหน้าฉลอง (ดาว/ตราใหม่/คู่หูโตขึ้น) ให้เองผ่าน `postMessage` เกมไม่ต้องทำ UI เพิ่ม
- `Learn5G.active` = true เมื่อเปิดจากบัญชีนักเรียน, `Learn5G.studentName` = ชื่อเล่นสำหรับทักทาย

## กติกาฝั่งเซิร์ฟเวอร์ (ความปลอดภัย)

| เรื่อง | การป้องกัน |
|---|---|
| โทเคน | เซ็น HMAC-SHA256 ผูก นักเรียน + เกม + รอบเล่น หมดอายุ 4 ชั่วโมง ปลอม/แก้ไขไม่ได้ |
| โทเคนใน URL | อยู่หลัง `#` (ไม่ถูกส่งไปที่เซิร์ฟเวอร์ใด) และ SDK ลบออกจากแถบที่อยู่ทันที |
| ค่าผลลัพธ์ | ตรวจช่วงค่าทุกฟิลด์ ดาวห้ามเกินความแม่นยำจริง (>=90% ได้ 3 ดาว, >=70% ได้ 2, >=40% ได้ 1) |
| ปั่นผล | จำกัด 30 ครั้ง/นาที/นักเรียน และไม่เกิน 200 ผลต่อหนึ่งรอบการเล่น |
| ข้อจำกัดที่ต้องรู้ | ผลมาจากเกมฝั่งเบราว์เซอร์ จึงเป็นการ "รายงานด้วยตัวเอง" เด็กที่เก่งเทคนิคอาจปลอมคะแนนตัวเองได้ แต่ไม่กระทบผู้อื่น และโทเคนเปิดดูข้อมูลใครไม่ได้ |

## ข้อกำหนดเกม

- เกมต้องฝังใน `<iframe>` ได้ (ไม่ตั้ง `X-Frame-Options: DENY`) ถ้าไม่ได้ ผู้ใช้กดปุ่ม "เปิดในแท็บใหม่" ได้ แต่จะไม่บันทึกผลเวลา
- ไม่จำเป็นต้องมีระบบล็อกอินของเกมเองอีกต่อไปเมื่อเปิดผ่านหน้า `/play`: ใช้ `Learn5G.studentName` แทน
